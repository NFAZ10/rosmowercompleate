🎯 KEY FEATURES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🛰️  GPS-BASED ROUTE RECORDING
    • Real-time waypoint collection with quality filtering
    • HDOP threshold (default: 2.0) rejects poor GPS
    • Live distance calculation using Haversine formula
    • Configurable waypoint spacing (default: 1.0m)

🎬 INTELLIGENT STATE MANAGEMENT
    • State machine: IDLE → RECORDING → PAUSED
    • Pause/resume capability for interruptions
    • Cancel option to discard bad recordings
    • Maximum recording time protection (10 minutes)

🗺️  ZONE GRAPH & PATH PLANNING
    • Automatic zone connectivity graph generation
    • Dijkstra's algorithm for shortest path
    • Multi-zone path planning (A → B → C → D)
    • Handles disconnected zones gracefully

🛡️  REAL-WORLD ROBUSTNESS
    • GPS quality monitoring and visualization
    • Speed limits per route type for safety
    • Path width accounting for GPS drift (1-3m)
    • Mow-during-transit flag control
    • Comprehensive error handling and logging

🎨 ROUTE TYPES
    • DRIVEWAY         - Paved paths (0.8 m/s max)
    • GATE_PASSAGE     - Narrow gates (0.3 m/s max)
    • AROUND_BUILDING  - Around structures (0.5 m/s max)
    • NARROW_PATH      - Tight spaces (0.4 m/s max)
    • ROAD_CROSSING    - Road crossings (0.6 m/s max)

🔄 BIDIRECTIONAL SUPPORT
    • Single recording creates two-way route
    • Efficient route reuse
    • Automatic reverse path generation

📊 ZONE PRIORITY SYSTEM
    • Priority 1-3:  Low (mow when convenient)
    • Priority 4-7:  Medium (normal schedule)
    • Priority 8-10: High (visible areas, mow first)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. BUILD THE SYSTEM
   ─────────────────────────────────────────────────────────────────────────
   cd /mnt/nova_ssd/rosmowercompleate
   colcon build --packages-select rosmower_msgs rosmower
   source install/setup.bash
   ./setup_multi_zone_storage.sh

2. LAUNCH ALL NODES
   ─────────────────────────────────────────────────────────────────────────
   ros2 launch rosmower zone_and_route_management.launch.py

   # In another terminal:
   ./start-web-server.sh

3. ACCESS WEB UI
   ─────────────────────────────────────────────────────────────────────────
   http://localhost:8080/routes

   Then:
   • Wait for 🟢 GREEN GPS indicator
   • Select From/To zones
   • Click "Start Recording"
   • Walk the route slowly
   • Click "Stop & Save"

EXAMPLE 1: Record a driveway route
──────────────────────────────────────────────────────────────────────────────
1. Open: http://localhost:8080/routes
2. From Zone: "backyard"
3. To Zone: "frontyard"
4. Route Type: "DRIVEWAY"
5. Max Speed: 0.8 m/s
6. Path Width: 2.0 m
7. ✓ Bidirectional
8. Start Recording → Walk path → Stop & Save

Result: Route saved to routes/backyard_to_frontyard_YYYYMMDD_HHMMSS.yaml


EXAMPLE 2: Plan multi-zone path via ROS2
──────────────────────────────────────────────────────────────────────────────
ros2 service call /route/plan_path rosmower_msgs/srv/PlanPath \
  "{start_zone: 'backyard', end_zone: 'side_yard'}"

Response:
  route_ids: ['route_backyard_to_frontyard', 'route_frontyard_to_side_yard']
  total_distance: 28.5
  success: true
