┌──────────────────────────────────────────────────────────────────────────────┐
│ HARDWARE SETUP                                                               │
└──────────────────────────────────────────────────────────────────────────────┘
  Jetson USB ──→ VESC ID 0 (Left Motor)
                       ↓ CAN Bus (CAN-H, CAN-L, GND)
                 VESC ID 1 (Right Motor)

  Power: 24V LiFePO4 → Both VESCs
  Motors: 300W Hoverboard BLDC (15 pole pairs)

┌──────────────────────────────────────────────────────────────────────────────┐
│ BUILD & LAUNCH                                                               │
└──────────────────────────────────────────────────────────────────────────────┘
  # Build
  colcon build --packages-select vesc_driver --symlink-install
  source install/setup.bash

  # Launch
  ros2 launch vesc_driver vesc_driver.launch.py

  # With custom params
  ros2 launch vesc_driver vesc_driver.launch.py \
    serial_port:=/dev/ttyACM0 \
    wheel_radius:=0.0875 \
    wheel_separation:=0.52

┌──────────────────────────────────────────────────────────────────────────────┐
│ VESC TOOL CONFIGURATION                                                      │
└──────────────────────────────────────────────────────────────────────────────┘
  VESC ID 0:
    ☑ Run motor detection (FOC mode)
    ☑ Set CAN ID = 0
    ☑ Enable "CAN Forward"
    ☑ CAN Baud = 500 kbit/s
    ☑ Current limits: Max 15A, Battery 10A
    ☑ Battery: LiFePO4 24V (cutoff 21V)

  VESC ID 1:
    ☑ Run motor detection (FOC mode)
    ☑ Set CAN ID = 1
    ☑ CAN Baud = 500 kbit/s
    ☑ Same current/battery settings

┌──────────────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
  ❌ No VESC detected
     → ls /dev/ttyACM*
     → sudo chmod 666 /dev/ttyACM0
     → sudo usermod -aG dialout $USER

  ❌ Motors don't move
     → Check VESC power LED
     → Test in VESC Tool first
     → Verify CAN bus wiring

  ❌ One motor works, other doesn't
     → Check CAN-H, CAN-L, GND connections
     → Verify CAN forwarding enabled (VESC 0)
     → Check VESC ID 1 configuration

  ❌ Erratic movement
     → Calibrate wheel_radius and wheel_separation
     → Check motor direction (swap 2 wires if needed)
     → Verify pole_pairs = 15

  ❌ High CPU usage
     → Reduce control_rate to 20 Hz
     → Reduce telemetry_rate to 5 Hz

┌──────────────────────────────────────────────────────────────────────────────┐
│ CALIBRATION                                                                  │
└──────────────────────────────────────────────────────────────────────────────┘
  1. Wheel Radius:
     • Drive straight 1 meter
     • Measure actual distance
     • wheel_radius *= (actual / expected)

  2. Wheel Separation:
     • Rotate 360° (cmd_vel angular.z = 1.0)
     • Measure actual rotation
     • wheel_separation *= (expected / actual)

  3. Verify in RViz odometry visualization
