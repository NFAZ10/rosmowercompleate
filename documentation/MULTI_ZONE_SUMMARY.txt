┌─────────────────────────────────────────────────────────────────────────────┐
│ 🚀 QUICK START (5 STEPS)                                                    │
└─────────────────────────────────────────────────────────────────────────────┘

  1. Build:
     $ ./build-multi-zone.sh

  2. Setup Storage:
     $ ./setup_multi_zone_storage.sh

  3. Launch System (in Docker):
     $ docker-compose up -d
     $ docker exec -it rosmower bash
     $ source /ws/install/setup.bash
     $ ros2 launch rosmower zone_and_route_management.launch.py

  4. Start Web Server:
     $ ./start-web-server.sh

  5. Access Web UI:
     http://<robot-ip>:8080/routes

  ⏱️ Time to first route: ~10 minutes

  Scenario: Multi-Zone Residential Property

    Property Layout:
      ┌─────────────┐
      │ Front Yard  │ Zone 1: 30m², Priority 5
      └──────┬──────┘
             │ Route 1: Driveway (15m, paved)
      ┌──────▼──────┐
      │ Side Yard   │ Zone 2: 20m², Priority 3
      └──────┬──────┘
             │ Route 2: Gate passage (5m, narrow)
      ┌──────▼──────┐
      │ Back Yard   │ Zone 3: 50m², Priority 8
      └─────────────┘

    Workflow:
      1. Record all 3 zones using existing zone recorder
      2. Walk driveway while recording Route 1 (Front → Side)
      3. Walk gate area while recording Route 2 (Side → Back)
      4. System automatically generates connectivity graph
      5. Plan mission: Front → Side → Back (priority 8 highest)
      6. Robot autonomously mows all zones with safe transit

    Results:
      ✅ No manual intervention during transit
      ✅ GPS-guided navigation through driveway and gate
      ✅ Safety: No mowing during transit
      ✅ Efficiency: Optimal path (shortest distance)
      ✅ Automation: Multi-zone autonomous operation
