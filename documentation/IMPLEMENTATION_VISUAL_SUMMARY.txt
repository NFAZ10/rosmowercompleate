    if state != RECORDING:

╔═══════════════════════════════════════════════════════════════════════════════╗
║ DOUGLAS-PEUCKER POLYGON SIMPLIFICATION                                        ║
╚═══════════════════════════════════════════════════════════════════════════════╝

  Algorithm:
    function douglasPeucker(points[], epsilon):
        dmax = 0
        index = 0
        
        # Find point with max distance from line
        for i in 1 to (n-1):
            d = perpendicularDistance(points[i], line(points[0], points[n]))
            if d > dmax:
                index = i
                dmax = d
        
        # If max distance > epsilon, recursively simplify
        if dmax > epsilon:
            recResults1 = douglasPeucker(points[0...index], epsilon)
            recResults2 = douglasPeucker(points[index...n], epsilon)
            return recResults1 + recResults2
        else:
            return [points[0], points[n]]
  
  Example:
    Input:  50 waypoints, tolerance = 0.3m
    Output: 18 waypoints (64% reduction)
    
  Benefits:
    • Preserves polygon shape
    • Reduces storage and processing
    • Keeps sharp corners
    • Configurable tolerance

╔═══════════════════════════════════════════════════════════════════════════════╗
║ POLYGON AREA CALCULATION (SHOELACE FORMULA)                                   ║
╚═══════════════════════════════════════════════════════════════════════════════╝

  Formula:
    For vertices (x₁,y₁), (x₂,y₂), ..., (xₙ,yₙ):
    
    Area = 0.5 * |Σᵢ(xᵢ * yᵢ₊₁ - xᵢ₊₁ * yᵢ)|
  
  Implementation:
    area = 0
    for i in range(n):
        j = (i + 1) % n
        area += points[i].x * points[j].y
        area -= points[j].x * points[i].y
    area = abs(area) / 2.0
  
  Coordinate System:
    • Uses local UTM projection (not lat/lon directly)
    • Reference point = first waypoint
    • All points converted to meters from reference
    • Accurate for zones up to several km²

╔═══════════════════════════════════════════════════════════════════════════════╗
║ SELF-INTERSECTION DETECTION                                                   ║
╚═══════════════════════════════════════════════════════════════════════════════╝

  Algorithm (Line Segment Intersection):
    for each edge E1 in polygon:
        for each edge E2 in polygon:
            if E1 and E2 are not adjacent:
                if segments_intersect(E1, E2):
                    return "Self-intersection detected"
    return "Polygon is valid"
  
  CCW Test (Counter-ClockWise):
    ccw(A, B, C) = (C.y - A.y) * (B.x - A.x) > (B.y - A.y) * (C.x - A.x)
    
    segments_intersect(A, B, C, D):
        return ccw(A,C,D) != ccw(B,C,D) and ccw(A,B,C) != ccw(A,B,D)
  
  Usage:
    • Validates polygon before saving
    • Warns user if self-intersection found
    • Helps catch recording errors
