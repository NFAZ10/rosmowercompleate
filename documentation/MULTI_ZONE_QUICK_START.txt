┌──────────────────────────────────────────────────────────────────────────────┐
│ 📍 RECORD YOUR FIRST ROUTE (10 MINUTES)                                     │
└──────────────────────────────────────────────────────────────────────────────┘

  1. Open http://<robot-ip>:8080/routes in browser
  2. Wait for GPS indicator to turn 🟢 GREEN (HDOP < 1.5)
  3. Select "From Zone" (e.g., backyard)
  4. Select "To Zone" (e.g., frontyard)
  5. Choose route type: DRIVEWAY
  6. Set max speed: 0.5 m/s
  7. Set path width: 2.0 meters
  8. Check ✅ "Bidirectional"
  9. Click ▶️ "Start Recording"
  10. Walk the intended path slowly
  11. Watch waypoints accumulate in real-time
  12. Click ⏹️ "Stop & Save"
  13. Done! Route saved to /ws/routes/

┌──────────────────────────────────────────────────────────────────────────────┐
│ 🎨 GPS QUALITY GUIDE                                                         │
└──────────────────────────────────────────────────────────────────────────────┘

  🟢 GREEN   (HDOP < 1.5)   - Excellent! Record routes now
  🟡 YELLOW  (HDOP 1.5-2.0) - Good, acceptable quality
  🔴 RED     (HDOP > 2.0)   - Poor, waypoints rejected

  Tips for good GPS:
  • Stand in open area with clear sky view
  • Avoid trees, buildings, metal structures
  • Wait 5-10 minutes after power-on for GPS lock
  • Check antenna is properly connected
  • Ensure RTK corrections are active (if available)

┌──────────────────────────────────────────────────────────────────────────────┐
│ 🗺️  ROUTE TYPES                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

  🚗 DRIVEWAY          - Main paved routes (max speed: 0.8 m/s)
  🚪 GATE_PASSAGE      - Through gates/fences (max speed: 0.3 m/s)
  🏢 AROUND_BUILDING   - Around structures (max speed: 0.5 m/s)
  🛤️  NARROW_PATH      - Tight paths (max speed: 0.3 m/s)
  🛣️  ROAD_CROSSING    - Across roads (max speed: 0.5 m/s)

┌──────────────────────────────────────────────────────────────────────────────┐
│ 🐛 TROUBLESHOOTING                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

  ❌ GPS is RED/YELLOW
     → Move to open area, wait 5-10 min, check antenna
     → ros2 topic echo /gps/fix --once

  ❌ Route not saving
     → Check permissions: sudo chown -R $USER:$USER /ws/routes/
     → Check logs: ros2 node logs route_manager

  ❌ Web UI not loading
     → Restart: ./start-web-server.sh
     → Test: curl http://localhost:8080/api/routes/list

  ❌ Nodes not starting
     → Rebuild: colcon build --packages-select rosmower_msgs rosmower
     → Source: source install/setup.bash
     → Launch with logs: ros2 launch ... --screen

  ❌ Path planning fails
     → Verify zones exist: ls /ws/zones/
     → Check routes exist: ls /ws/routes/
     → Ensure bidirectional routes recorded
