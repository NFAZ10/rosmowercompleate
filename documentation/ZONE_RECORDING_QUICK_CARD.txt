└──────────────────────────────────────────────────────────────────────────────┘

  Subscribe:
    /gps/fix                          GPS position (NavSatFix)
    /visual_odometry/pose             Visual odom (future) (PoseStamped)

  Publish:
    /zone/record/status               Detailed status (ZoneRecordingStatus)
    /zone/record/state                Simple state (String: IDLE/RECORDING/PAUSED)
    /zone/record/waypoints            Current path (Path)
    /zone/record/polygon              Current polygon (PolygonStamped)

┌──────────────────────────────────────────────────────────────────────────────┐
│ 🔧 ROS2 SERVICES                                                             │
└──────────────────────────────────────────────────────────────────────────────┘

  /zone/record/start      StartZoneRecording    Start recording with zone name
  /zone/record/stop       StopZoneRecording     Stop and save zone
  /zone/record/control    ControlZoneRecording  Pause/resume/cancel (cmd: 0/1/2)

  Examples:
    $ ros2 service call /zone/record/start rosmower_msgs/srv/StartZoneRecording \
        "{zone_name: 'Front Yard', priority: 5, use_visual_odometry: false}"
    
    $ ros2 service call /zone/record/stop rosmower_msgs/srv/StopZoneRecording \
        "{save_zone: true, auto_close: true, simplify: true, simplification_tolerance: 0.3}"

┌──────────────────────────────────────────────────────────────────────────────┐
│ 🔍 TROUBLESHOOTING                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

  Problem: GPS not working
    → Check: ros2 topic echo /gps/fix --once
    → Fix: Ensure GPS module connected and driver running

  Problem: No waypoints recording
    → Check GPS quality (must be green/yellow, not red)
    → Check you're moving >0.5m between points
    → Check state is "RECORDING" not "PAUSED"

  Problem: Web UI not loading
    → Check: ps aux | grep web_server.py
    → Fix: python3 web_server.py

  Problem: Zone not saving
    → Check: ros2 service list | grep zone/save
    → Fix: Launch zone_manager node

  View logs:
    $ ros2 run rosmower zone_recorder.py  # Run in foreground
